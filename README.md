## 🚀 NeonCore

**Privacy-first AI assistant for Windows — your files never leave your device.**

NeonCore is a Windows desktop AI assistant built for people who don't want their
documents uploaded to someone else's cloud. It reads, analyzes, and writes files
locally through seven built-in tools, with voice command support and a credit-based
model instead of a subscription.

| | |
|---|---|
| **Platform** | Windows (Electron + React) |
| **Tools** | Reading · Analysis · Writing · File creation · Code · PDF · Excel |
| **Privacy** | Zero data retention verified on every model integration |
| **Compliance** | KVKK-compliant · no telemetry · no training on your data |
| **Pricing** | Free credits to start, then one-off credit packs — no subscription |

👉 **[neondijital.com/urunler/neoncore](https://neondijital.com/urunler/neoncore)**
